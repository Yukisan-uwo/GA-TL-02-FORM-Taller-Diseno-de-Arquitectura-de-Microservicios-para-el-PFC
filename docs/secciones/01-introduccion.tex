\section{Introducción}

El Sistema de Gestión de Refuerzos Académicos (SGRA)
permite gestionar las solicitudes de refuerzo, la programación
de sesiones, la asignación de espacios y el seguimiento
de las actividades académicas entre estudiantes, docentes
y personal administrativo.

A partir de los diagramas de contexto y contenedores
del sistema, se propone una arquitectura de microservicios
que permita distribuir las responsabilidades del negocio
en servicios independientes, cada uno con sus propios datos
y mecanismos de comunicación.

El diseño considera la incorporación de un API Gateway,
la comunicación síncrona y asíncrona entre servicios y
la elaboración del diagrama de componentes C4 de nivel 3.
Las decisiones arquitectónicas se relacionan con los
requisitos funcionales y no funcionales establecidos
para el SGRA.
