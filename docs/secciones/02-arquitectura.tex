\section{Arquitectura propuesta}

Integro el diseño en cinco vistas del archivo
\path|docs/diagramas/c4-nivel-3.drawio|: canales generales, componentes
de Refuerzos, componentes de Identidad, Académico y Espacios, componentes
de apoyo y distribución de eventos. Mantengo una base PostgreSQL
independiente por servicio y el API Gateway como entrada única de los
clientes web y móvil. Diferencio llamadas internas, SQL, REST síncrono
y AMQP asíncrono mediante la leyenda del diagrama.

Propongo los componentes de outbox, consumo idempotente y control de
versiones que detallo en mi sección de comunicación asíncrona. Para
integrar el SGA propongo una API HTTPS cuyo contrato debo comprobar;
para el correo propongo Gmail mediante SMTP sobre TLS. Para respaldos
mantengo la coordinación por servicio, sin dar acceso a una base ajena.
No presento estas decisiones como componentes ya implementados.

Incluyo a continuación las cinco vistas de la exportación PDF.
Para revisar componentes y conectores con mayor detalle, utilizo
también el PDF independiente en \path|docs/diagramas/c4-nivel-3.pdf|.
